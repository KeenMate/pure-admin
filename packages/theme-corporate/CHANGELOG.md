# Changelog

All notable changes to @keenmate/pure-admin-theme-corporate will be documented in this file.

## [2.0.0] - 2026-02-21

Rebuilt with `@keenmate/pure-admin-core@2.0.0` — responsive grid columns now use container queries.

---

## [1.5.1] - 2026-02-15 ✅ Published

Rebuilt with `@keenmate/pure-admin-core@1.5.1` — includes 7 new data display components, CSS container query support, ghost card variant, and dark mode shadow fix.

---

## [1.0.0-rc01] - 2026-01-01

First release candidate.

### Added
- Professional blue corporate theme
- Light/dark mode support via `.pa-mode-light` / `.pa-mode-dark` classes
- Theme manifest (`theme.json`) declaring capabilities

### Fixed
- Dark mode navbar dropdown visibility (white text on dark background)
