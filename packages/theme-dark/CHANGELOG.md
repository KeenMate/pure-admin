# Changelog

All notable changes to @keenmate/pure-admin-theme-dark will be documented in this file.

## [1.0.0-rc01] - 2026-01-01

First release candidate.

### Added
- Dark theme with neutral gray palette
- Light/dark mode support via `.pa-mode-light` / `.pa-mode-dark` classes
- Color variants via CSS classes: `.pa-color-blue`, `.pa-color-green`, `.pa-color-red`
- Theme manifest (`theme.json`) declaring capabilities

### Changed
- Consolidated dark-blue, dark-green, dark-red variants into single theme with CSS class switching
